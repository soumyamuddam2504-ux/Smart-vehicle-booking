# Project Memory

## Project Name
Smart Vehicle Match & Booking Platform

## Goal
Build a web application where users can:
- Sign up and log in
- Enter trip requirements (budget, passengers, trip type, duration)
- Get vehicle recommendations with explanations
- Book vehicles
- View bookings in a dashboard

## Decisions
- Build step by step
- Use mock/static data initially
- Focus on end-to-end flow first
- Keep UI simple and clean

## Tech Stack
- Not finalized yet (to be decided)

## Rules
- Claude must not start coding immediately
- Must explain approach before implementation
- Must wait for user confirmation before coding

## Notes
- Keep code modular and scalable
- Prioritize clarity over complexity
